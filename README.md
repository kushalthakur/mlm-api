## mlm api's
Multi Level Marketing api, mlm tree.<br />
TypeScript (Webpack), NodeJs, Express and MySQL (Sequelize).<br />

## Project setup

In the project directory, you can run:
1. ``` npm install ```
2. ```npm run dev```

Runs the app in the development mode.<br />
Open [http://localhost:PORT](http://localhost:PORT) to view it in the postman.

## Features available in the application:
1. Perfect Folder Structure
2. User signup
3. Login
4. Admin create mlm tree
